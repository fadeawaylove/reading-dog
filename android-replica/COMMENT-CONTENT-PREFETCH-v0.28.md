# v0.28 段评内容提前缓存

默认开启阅读设置中的「提前缓存段评内容」。阅读时按实际排版页预取当前页和后两页内有段评段落的第一页，每页 20 条；接近章末时预取下一章开头最多三个有段评的段落。头像和配图仍按需加载。

面板首屏显示后立即准备下一页；准备好的页只有实际追加时才推进显示游标，再准备后续页。列表不足一屏时自动补足，末页停止。缓存键包括书籍、章节、正文版本、段落和请求游标，同一键共享在途请求，评论按 ID 去重。映射失效时保留已显示内容并提供重新验证，不能继续使用旧分页。刷新后页成员或后继游标变化会丢弃旧后续页。

文字缓存逻辑载荷上限 30 MiB，按最近使用淘汰，与图片缓存独立；缓存过期后先显示再后台刷新，失败不清空。网络恢复刷新过期的已显示页。后台失败采用 2 秒、4 秒退避，最多三次失败，用户操作或网络恢复可重新触发。

客户端单并发优先级为主动查看、面板下一页、正文附近预取；正文/目录有请求时延后启动段评请求。切段、关闭、离开阅读及关闭开关会淘汰过时排队任务，迟到结果只能进入对应缓存，不能修改新面板。关闭开关仍可主动查看及读取已有缓存。

后端段评使用独立上游身份、请求锁及专用 HTTP 调度队列，正常正文和目录请求不等待段评锁。队列最多保留 32 个等待请求。部署保留现有 data、字体、版本和服务配置。
