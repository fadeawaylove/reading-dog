# 阅读页加入书架

按已确认的菜单设计实现。本次为 0.23 本地试用构建，未发布新版本。

- 顶栏书名与更多之间增加固定宽度入口：未加入显示「＋ 加入书架」，加入后原位显示「✓ 已在书架」，不重复添加。
- 阅读菜单和阅读设置共用该入口；加入/移出只更新按钮，不关闭设置、不重新排版正文。
- 更多改为省略号图标，保留原书签/段评操作；仅在已加入时提供「移出书架」。移出保留进度、书签和缓存。
- 详情页的开始阅读与目录跳转均携带当前书籍信息，支持离线加入；旧入口缺少书籍信息时异步获取，加载中禁止重复请求，失败可重试，页面退出后忽略返回。
- 加入/移出使用短 Toast，不增减页面布局；已有书籍禁用加入操作。

验证：正式源代码构建成功，APK 签名验证及 `git diff --check` 通过。ADB 无连接设备，未执行设备测试与视觉验收。待验证：两种菜单加入/移出、离线与失败重试、重启持久化、进度保持、长书名/放大字体/夜间显示。
