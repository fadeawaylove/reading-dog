# 段评预热与阅读控制

## 行为

- 后续五章串行预热段落映射和评论数量，优先下一章。正文缓存完成会触发补齐；评论正文仍按点击加载。
- 磁盘缓存的映射、正文和版本一致时，在排版前恢复数量；过期缓存先显示再刷新。邻章预热完成更新布局，不取消正在进行的翻页动画。未完成预热时仍先展示正文。
- 音量键默认开启：＋下一页，−上一页。设置提供开关；弹层和菜单中的音量键交还系统；长按只翻一次，忙碌时不排队。
- 间距滑杆范围 1.60–3.20，步长 0.01，松手重排，保留字符偏移。旧三档迁移为 2.05/2.20/2.40，分页缓存使用精细间距。段距在标准至宽松之间插值，保留旧档端点。
- 评论保留秒级 `create_timestamp`，以设备时区显示 `yyyy-MM-dd HH:mm`。旧 page-v2 缓存保留，内部 schema=3 标记时间字段已解析，旧页先显示再刷新；无效时间不显示。

## 复跑

运行 `build-controls.ps1` 和 `tests/build-reading-controls.ps1`，覆盖安装应用与独立测试 APK。执行 `python tests/run-reading-controls.py`；MIUI 限制 instrumentation 注入触摸时，脚本在收到控件真实坐标后通过已授权 root shell 注入滑动。测试期间不要并发操作设备。

`--offline` 只选择离线检查，不改变网络；需由调用者保存、关闭并最终恢复网络。测试保存/恢复阅读偏好、进度和最近阅读时间；正式验收仍应先备份用户数据。
