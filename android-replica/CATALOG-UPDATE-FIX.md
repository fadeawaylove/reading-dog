# 连载更新无法翻页修复（0.4）

原因：阅读器启动读取 SQLite 目录，没有自动失效机制；`needChapter` 把缓存目录末尾直接当作真实末尾。因此《穿越乱世：每天一份拼好饭》缓存 611 条，而实时接口已有 612 条时，仍提示“已读到最后一章”。

修复：末章继续翻页时强制联网检查目录，新增章节存在则直接打开；确认接口成功且没有下一章后才提示“已是最新章节，暂无更新”。失败保留原文并提供点击重试，检查期间重复点击合并。刷新按当前章节 ID 重定位，更新目录总数、阅读进度、当前绘制帧与相邻章节缓存。导航期间旧回调不跳转阅读位置。目录面板手动刷新复用相同的目录应用逻辑。
