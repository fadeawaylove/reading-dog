# 首页书架更新（0.9）

进入首页或从阅读返回时，立即显示本地书架，再由独立串行线程刷新目录和详情。成功检查的目录 5 分钟内跳过自动请求，下拉刷新强制检查全部书架；同一轮进行中的请求合并，不启动重复批次。搜索状态不接受下拉，后台结果更新不会覆盖搜索结果。

搜索栏下方短暂显示刷新状态，失败保留本地书籍并提供点击重试；成功状态约 2.5 秒后收起。保持原单页主页结构，不增加独立书架页面。

## 目录和新章

- 首页总章节以最近成功获取并校验的完整目录为准，不再直接取旧阅读记录里的总数；当前章节按保存的章节 ID 映射目录顺序。
- 最近阅读与对应书架行显示“有新章 · N”。基准是此前已知目录末章；没有旧目录时使用旧书籍详情中的章节数量，未知则首次建立基准，不把全部未读内容当作更新。
- 标记持久化；读到新增章节时推进已确认基准，回翻旧章节不会重新出现已确认的更新标记。
- 自动刷新与下拉刷新均不写 `progress`，也不改变添加时间、最近阅读时间或排序。真正阅读仍由阅读器保存章节 ID/原文偏移。
- SQLite 从版本 1 非破坏升级到 2，仅新增 `library_updates`，保存检查时间和已确认的目录尾章节 ID。原书架、正文缓存、阅读位置和书签表保留。
